## 6. Questions for you

1. **The photograph originals' content credentials.** 63 originals (32 in `assets/`, 31 in
   `garage/assets/`) carry content credentials naming the tool that drew them. The published copies
   on the site carry none (§ 5). Once the repository is public, anyone can read the originals.
   - **(a) Keep them as they are.** Nothing changes. The credentials say where the images came from.
   - **(b) Strip them in a new commit.** The working tree is clean from then on. The older commits
     still hold the originals, so the history keeps them.
   - **(c) Strip them and rewrite the history.** Nothing public carries them. Every commit and tag
     changes, `specs-v1` to `specs-v8` move, and the beads' cited shas go stale. Destructive.
2. **The code's licence** (C3 § 7, item 4). The README says Vandalway Industries reserves all rights
   in its code. Keep that, or name a licence before the switch.
3. **The ritual's drawing code at the press.** On a quiet network the result arrives 4.63 s after
   the press in both engines, and under an emulated slow phone network too (150 ms round trip,
   1.6 Mb/s). But the result waits for the certificate's drawing code, which is fetched when you
   press. Once, on this workstation, the network stalled: the 26 KB file took 4.4 s and the result
   came at 7.0 s. Fetching the drawing code quietly after the page has loaded would keep the four to
   five seconds on a bad connection. The page's first load would carry about 80 KB more. Change it,
   or leave it.
4. **X4 item 3's wording.** It still names the browser's offline switch, which its test no longer
   uses (since `specs-v4`, the server is stopped instead). Reword it to say what the test does: yes
   or no.
5. **RC5's distance pattern** (C3 § 7, item 2). It matches any word ending in "m" or "ft", so a
   paper can pass only by avoiding words like "from". Approve narrowing it to numbers followed by a
   unit, or leave it.
6. **The certificate golden, second look.** The guilloche border is now 0.7 (C2 red-pen). See
   `garage/pack/exemplars/certificate-golden.png`.
7. **The 1997 counter cell.** The golden's counter cell has a lighter grey frame on a faint green;
   the counter we draw is darker, with a black frame. It is within the approved "counter digits
   change" allowance; this is for your eye. See [the 1997 page on the internal copy](c4/screens/vandalwayind-1997-1440.png).
8. **Staging's build id** (no decision needed): staging was walked on the build of 7f198d9 and now
   serves the build of a918f13, the packet's own commit (`deploy/deploy-log.md`, Phase 7 staging,
   run 5). Nothing under `src/` changed between them; the pages are the same.
